This code utilizes the MPNN model of GNN to learn the fragmentation patterns of compounds in the MASSBANK database under high-resolution mass spectrometry conditions, in order to predict the fragmentation patterns of compounds in pharmaceuticals and personal care products under mass spectrometry conditions. Ultimately, this enables more accurate screening of suspect compounds in environmental samples.
This code implements an end-to-end graph neural network (GNN) framework for predicting mass spectra (MS2) from molecular structures, covering the complete pipeline from data parsing and graph construction to model training and evaluation. First, the load_mgf_with_ms2 function reads MGF-format spectral files, extracting the SMILES string, precursor ion information, and MS2 peak lists for each molecule, while filtering out noise peaks with intensities below 100. Subsequently, the mol_to_graph function employs RDKit to convert molecular structures into graph representations, where node features are 12-dimensional one-hot encodings of atom types (C, N, O, F, S, Cl, Na, Al, P, Br, K, Mg). The ms2_to_vector function then maps each MS2 spectrum to a fixed-length 326,000-dimensional vector by retaining only the top 200 most intense peaks, applying square-root transformation, and performing normalization, which serves as the prediction target. For the model architecture, the MPNNWithAttention class constructs a graph neural network with an attention mechanism: node features are first projected to 256 dimensions via a linear layer, followed by three GATConv layers (each with four attention heads) for message passing, after which global mean pooling yields a graph-level representation, and a final fully connected layer outputs the 326,000-dimensional MS2 spectrum vector. During training, the AdamW optimizer and a ReduceLROnPlateau learning rate scheduler are employed, with a composite loss function combining MSE and cosine similarity (weighted by α = 0.5). Model performance is evaluated on the validation set after each epoch, and checkpoints are saved every 10 epochs. In the testing phase, inference is performed on the test set to compute the full-spectrum cosine similarity (scaled by Sigmoid) and MSE. Furthermore, the top 200 most intense peaks from both the predicted and ground-truth spectra are selected to calculate intensity similarity (cos_200) and m/z position similarity (cos_mz), respectively, while comparison plots of predicted versus ground-truth spectra are generated and saved. Overall, this code enables end-to-end prediction from molecular structures to mass spectra vectors and provides multi-dimensional evaluation metrics, making it well-suited for graph neural network-based compounds mass spectrum prediction research.
