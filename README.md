This code utilizes the MPNN model of GNN to learn the fragmentation patterns of compounds in the MASSBANK database under high-resolution mass spectrometry conditions, in order to predict the fragmentation patterns of compounds in pharmaceuticals and personal care products under mass spectrometry conditions. Ultimately, this enables more accurate screening of suspect compounds in environmental samples.
